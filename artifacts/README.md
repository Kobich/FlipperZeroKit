Единая библиотека :flipper включает BLE/RPC, файлы и UI-блок ui; отдельного UI Gradle-модуля нет. FlipperScreen(flipper) — один общий экран с текущими блоками устройства/передачи/файлов.

В 1.8 восстановление передачи и очистка частичного файла блокируют экран диалогом с круговым индикатором. Диалог закрывается по завершении попытки. Прошли 42 unit-теста. [Хронология](../docs/VALIDATION.md#25-ноября-2026--модальный-диалог-восстановления-передачи)

В 1.7 весь интерфейс переведён на английский, включая уведомления. Действия **Ping**, **Power Info**, обновление сведений и отключение собраны в одну строку. Прошли 42 unit-теста. [Хронология](../docs/VALIDATION.md#25-ноября-2026--английский-интерфейс-и-компактная-строка-действий)

В 1.6 появилась компактная сводка с зарядом, прошивкой и объёмом SD-карты. Сведения сохраняются на телефоне. Новый запрос выполняется по кнопке после первой загрузки. Прошли 42 unit-теста. [Хронология](../docs/VALIDATION.md#25-ноября-2026--краткая-сводка-устройства-и-сохранение-сведений)

В 1.5 готовность RPC подтверждается ответом Ping, ручной выбор сохраняется сразу, а согласование MTU выполняется перед обнаружением GATT-сервисов. Отчёт о подключении содержит этапы и коды ошибок. Прошли 40 unit-тестов. Проверка подключения к Libam на Android 16 предстоит. [Хронология](../docs/VALIDATION.md#25-ноября-2026--libam-подключается-и-сразу-теряет-rpc)

APK 1.5–1.8 подписаны одним облачным debug-ключом. Для установки после опубликованного APK 1.4 с другой подписью потребуется сначала удалить установленную версию.

В 1.4 добавлены автонумерация (2)/(3), журналы очистки partial, мягкая отмена upload с fallback восстановления, foreground connectedDevice-передача с уведомлением и отменой, ограниченный reconnect без фонового polling. Общего лимита длительности передачи нет; технические таймауты обмена сохраняются. Клиент хоста должен жить до конца операции.
