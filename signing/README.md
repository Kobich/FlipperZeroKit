# Debug-подпись прототипа

Канал 1.13 и новее использует прежний Android debug-key. Отдельный production/release ключ не заводим. APK debug и пробный release/R8 подписываются одним сертификатом из prototype-sha256.txt.

По умолчанию используется существующий файл ~/.android/debug.keystore. На другой машине FLIPPER_PROTOTYPE_KEYSTORE должен указывать на тот же ключ (путь к файлу, не его содержимое). Alias androiddebugkey и стандартный debug-пароль Android. В проект приватный ключ не копировался; *.keystore/*.jks и .signing исключены из Git.

Перед сборкой выполняется :sample:verifyPrototypeSigning. Отсутствующий файл или несовпавший отпечаток останавливают сборку, новый ключ автоматически не создаётся. Публичный SHA-256 сертификата закреплён в prototype-sha256.txt. Замена этой записи означает осознанную смену канала и несовместимость обновления.

Сохрани резервную копию существующего debug-key приватным способом, если переносишь/переустанавливаешь окружение. Для облачной сборки нужен тот же файл через приватное хранилище окружения. Сам ключ в Git и в artifacts не помещать.

Старый облачный ключ 1.5–1.12 утрачен по ответу пользователя. Сделать обновление поверх 1.11 с сохранением данных существующим локальным ключом невозможно; дальнейшие обновления нового канала сохраняют подпись. Ротация ключей/production-публикация в этот прототип не входят.
