# Проверки проекта

## 24 ноября 2026 — одна встраиваемая UI-фича и ручной тест-план

По уточнению пользователя добавлено R09: Flipper — один пункт внешней нижней навигации, а не два пункта «Устройство» и «Файлы». Создана Android Compose Library :flipper-ui с публичной FlipperScreen и необязательным FlipperConnectionController. Она не содержит Activity, Hilt, внешнего NavController/нижнего бара/темы. Sample владеет внешней навигацией, клиентом и политикой reconnect. Core :flipper не менялся.

Экраны, UI-state, ViewModel, SAF и components перенесены из sample в internal UI-библиотеки. Два ViewModel принадлежат внешнему NavBackStackEntry; внутренние вкладки сохраняют форму/каталог/прокрутку и не очищают передачу. Активная операция видна баннером. Reconnect теперь привязан к входу/возврату фичи, а поворот не считается новым входом. Данные телефона открываются через application ContentResolver; Activity/Context в ViewModel не удерживается. После первого Lint замечание StaticFieldLeak устранено заменой поля Context на ContentResolver, без подавления проверки.

Финальный общий прогон в рабочем проекте: BUILD SUCCESSFUL, configuration cache reused.

## 24 ноября 2026 — подключение известного устройства без поиска

Добавлены getKnownDevices(), KnownBleDevice/KnownDevicesResult и UI выбора из сопряжённых BLE/dual/unknown и текущих системных GATT-подключений. Чтение вынесено на IO, дедупликация по адресу, подключённые первыми; признаки bond/GATT показаны раздельно. Обновление при входе и по кнопке не запускает scan и не сбрасывает клиент. Для списка/direct connect/autoreconnect используются connectPermissions; SCAN/location запрашиваются отдельно для поиска. RSSI для известного адреса null.

Sample: versionName 1.1-prototype, versionCode 2. После исправления импорта Compose финальный общий прогон завершился BUILD SUCCESSFUL: APK и AAR собраны, 29 существующих тестов RPC/framing/model прошли, Lint sample 0/0, flipper 0 ошибок/3 прежних GradleDependency. git diff --check прошёл. Это регрессионная проверка, не тест системного Bluetooth-списка на реальном телефоне.

Следующий физический сценарий: при уже подключённом/сопряжённом Flipper открыть приложение, выбрать его из «Уже известных устройств» без поиска, дождаться RPC ACTIVE и проверить Ping/DeviceInfo. Проверить также CONNECT без SCAN, Bluetooth off, отказ/отзыв CONNECT и активное другое приложение. Параллельная чужая RPC-сессия не считается пригодной для перенятия нашим клиентом. Прогон на устройстве пока не выполнен; подробности — PROTOTYPE.md.

## Физическое устройство

Известен Android 16; firmware Flipper пока неизвестна. Пользователь подтвердил положительный прогон и отдельно скачивание в нашем приложении; отправку ещё не проверял. Детальная фиксация — в первом разделе этого документа. Сам агент BLE-прогон не выполнял; Android 16 также не подтверждает ветку API 37.
Успешные тесты, Lint и сборка не означают, что BLE-поведение перепроверено физически.
